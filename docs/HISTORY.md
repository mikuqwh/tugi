# 项目简史

一句话：从「一个只能把视频转成 GIF 的小工具」做成「本地媒体工具台」。

## 时间线

| 阶段 | 做了什么 |
|---|---|
| 起点 | 验证 ffmpeg-kit 在 Android 上能用、`drawtext`/`palettegen` 的转义与画质参数 |
| S1 | 视频取音轨（能流复制就流复制，不能才重编码） |
| S2 | 决定不自编 ffmpeg，改用 full-gpl 预编译包，换全部格式能力 |
| S3 | 万能格式转换：输入类型按内容判定，输出按本机 ffmpeg 能力置灰 |
| S3.1 | 28 个格式的设备矩阵测试（逐个真转 + codec 校验） |
| S4 | 品牌化：改名为 Tugi、四组功能分页、可换背景与主题色、彩虹光效、设置面板 |
| S5 | 作品区：导出即入库、缩略图、排序检索、预览、分享、再编辑、容量管理 |
| 收尾 | 本地化、手势冲突、公开仓库整理（LICENSE / CI / 文档 / 合规） |

## 反复出现的设计取向

1. **命令与执行分离**：`lib/ffmpeg/` 全是纯函数，argv 可以逐字断言；
   执行、临时文件、错误文案在 `lib/services/`。
2. **诚实的数字**：体积预估给区间而不是假精度；做不到的格式置灰并说明原因。
3. **手势优先级明确**：可横滑换功能，但滑块、画布、文本选择手柄优先；
   顶区右滑开设置，列表顶部下拉开搜索。
4. **记录而非隐藏**：延期、取舍、实测数据都写进文档，`docs/` 保留全过程。

## 关于「对照实现」

早期开发参考过同类产品的交互与参数，但代码、文案、图标、背景均为本项目自行实现；
仓库中不包含任何第三方应用的资源或二进制。当前实现里的每一条参数都经过本机实测
（见 `docs/` 中带日期的报告）。
